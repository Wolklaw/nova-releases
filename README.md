# Nova: downloads

Nova is a local AI assistant for Windows, with its own window, its own language model and an Android phone app. The AI runs on your PC, not in a cloud.

Get the installer and the phone app from the [Releases](../../releases/latest) page. This repository only hosts the downloads; the source code is private.

More about the app: https://wolklaw.dev/projects/nova/

The Windows installer is not code-signed yet, so Windows SmartScreen may warn you before installing. Each release lists a SHA-256 checksum for every file.
